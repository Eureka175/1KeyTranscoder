## What this file does NOT establish

- It does not preserve the implementation. A SHA-256 of a gitignored file proves
  which bytes a result came from and **does not keep them**. If `work/` is deleted,
  the code and the measurements are gone and these hashes are a tombstone.
- It does not make the runs reproducible from a clean checkout, because the corpus
  (3.4 GiB) and the measurements are not tracked either.
- It does not say the results are correct. That is what the contract check, the
  independent channel and the regression suite are for.

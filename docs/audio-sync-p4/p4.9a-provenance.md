## 1. The corpus is read-only, and that is checkable

The phase reads 929 files (91 GB) and writes nothing into either directory. Every
record in `work/p4.9a-short/manifest.json` carries the file's sha256, so the claim
is verifiable rather than asserted:

```powershell
# re-hash the corpus and compare against the manifest
python work/p4.9a-short/inventory.py     # rewrites manifest.json
git status --short testsets/             # must be empty
```

`inventory.py` re-runs the full scan, so a corpus that had been modified would
produce a different manifest. No file was renamed, moved, deleted or rewritten:
the inventory **opens for reading only** and computes hashes with a read-only
handle.

## 2. What was reused rather than rewritten

The phase adds **no** ffprobe parser, **no** estimator and **no** sync algorithm.
Everything it measures comes from production code:

| need | production source used | how |
|---|---|---|
| container / stream facts | `core.probe.probe_streams` | same `-show_entries` table as the production video probe |
| audio model view | `core.audio_probe.build_audio_streams` | same builder the production path uses |
| PCM decode | the same `ffmpeg -map 0:a:N -f f32le -ac 1 -ar 48000` invocation as `channel_sync._decode_stream` | written to `work/p4.9a-short/raw/`, deleted per clip |
| fixed-delay estimate | `core.sync_estimate.estimate_pair` | called directly, at the production geometry |
| evidence gate | `core.channel_sync.effective_opts(None)` | thresholds **read**, never typed in |
| constancy | `core.sync_estimate.classify_constant` | same call signature the production path uses |
| plan geometry | `core.audio_sync_tv.required_window_count` | the production function, not a copied formula |
| whole production chain | `core.channel_sync.run_channel_sync(opts=None)` | Milestone C |

## 3. The independent verifier, and why it is not the estimator in disguise

`work/p4.9a-short/harness.py::independent_delay` shares **no code** with
`core.sync_estimate`:

| | production estimator | independent verifier |
|---|---|---|
| decimation | decimates to 8 kHz first | none — full 48 kHz |
| method | GCC-PHAT (phase transform, whitened) | plain `numpy.fft` cross-correlation |
| search | ±80 ms coarse, then ±8 samples fine | full ±100 ms in one pass |
| centre | median over accepted frames | whole-array peak, parabolic sub-sample |
| frequency weighting | PHAT whitening | none |

It is used for **reporting and cross-checking only**; it never supplies the shift
that gets applied.

**It must be able to refuse.** A cross-correlation always has an argmax, so an
unqualified peak would otherwise be reported as a number. The verifier therefore
requires (a) signal present — the same `-50 dBFS` floor the production estimator
applies to a frame, reused rather than invented — and (b) `peak_to_sidelobe >= 1.5`,
i.e. the peak must stand clear of the next-highest local maximum. When either
fails the case is `VERIFIER_NOT_QUALIFIED`, which is **not** counted as agreement
and **not** counted as failure.

This existed as a real harness defect during the phase: the first sweep run
reported `DISAGREE` on 188 pairs that were mostly a **silent** channel
(CH1/CH2 at ≈ -64 dBFS) with no signal to verify at all. Those lines are preserved
in `work/p4.9a-short/logs/superseded-pre-gate-results.jsonl`. The fix did not
loosen any production threshold; it stopped the verifier from answering questions
the material could not pose.

## 4. Reproduction

```powershell
# A -- inventory (writes manifest.json + inventory-summary.json)
python work/p4.9a-short/inventory.py
python work/p4.9a-short/by_surface.py

# smoke: one clip, whole chain, printed
python work/p4.9a-short/smoke.py

# B -- measurement over every usable clip (137 clips x 3 pairs)
python work/p4.9a-short/sweep.py --pairs "2-0 2-1 2-3"

# C -- the REAL production chain, opts=None (shipped defaults)
python work/p4.9a-short/prod_chain.py testsets/20260904/20260904_C1196.MP4
python work/p4.9a-short/apply_verify.py

# derived tables + the final report
python work/p4.9a-short/summarise.py
python work/p4.9a-short/fill_report.py
python work/p4.9a-short/reconcile.py
python work/p4.9a-short/link_check.py
```

Raw artifacts (gitignored, `work/`): `manifest.json`, `results.jsonl`,
`logs/`, `prod/`, `apply/`, plus the superseded pre-gate results.

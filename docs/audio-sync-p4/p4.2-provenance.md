### 2.1 What changed in each

```text

                                          coverage, confidence}

                          coverage), returning (ok, reason)
+ try_wide()             wide re-measurement that MUST pass evidence_ok before
                          adoption, and returns the failure reason
~ the two wide branches  now go through try_wide and cannot adopt a failure
+ the final adoption gate on the CHOSEN estimate before writing "fixed"
+ rows[i]["evidence"]    on every decision row
+ "evidence_insufficient" in _ESTIMATION_FAIL_REASONS
```

`core/audio_models.py`:

```text
+ _SYNC_REASON_STATUS["evidence_insufficient"] = SyncStatus.LOW_CONFIDENCE
```

**No other production file was touched.** No algorithm changed: GCC-PHAT, the
estimator maths, the delay sign convention and the integer-shift correction are
all untouched (`core/sync_estimate.py` and `core/sync_fix.py` hash-match their P3
values — §4).

## 8. Reproducing P4.1

```powershell
# the D6 regression suite -- TRACKED CODE ONLY, no corpus needed
python tests/audio_sync_p4/test_downstream_state.py

# the downstream state trace (24 probes)
python work/p4.1/trace_state_flow.py --json work/p4.1/trace.json

# the dangerous-loss consumer fixture -- needs the P3.11 plan arrays
python work/p4.1/consumer_fixture.py --json work/p4.1/consumer-fixture.json

# real-corpus state extraction, all six pairs
python work/p4.1/_states.py

# hash re-verification of everything P4.1 must not have changed
python work/p4.1/hash_verify.py

# the P4 suite, to confirm P4.1 did not disturb it
python tests/audio_sync_p4/test_production_sync.py
```

**Clean-run requirements:**

| command | needs |
|---|---|
| the D6 suite | **nothing beyond the repo** |
| the trace | nothing external |
| the consumer fixture | `work/p3/p311/plan/` — **skips with exit 3** if absent |
| the state extraction | same |
| hash verify | nothing external |
| the P4 suite | nothing external |

The first, second, fifth and sixth run anywhere. The third and fourth degrade to a
**reported skip**, never a pass — the brief's §40 rule.

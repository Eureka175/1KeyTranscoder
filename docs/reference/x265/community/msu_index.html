Проведенные в МГУ сравнения видеокодеков

MSU Graphics & Media Lab (Video Group)

Выпущен отчет о сравнении видеокодеков 2022 года

Проведенные сравнения

  • Введение в сравнение видеокодеков
    Как и почему сравниваются кодеки? Как правильно это делать и какими инструментами
    необходимо для этого пользоваться?

  • Старое сравнение видеокодеков (май 2003)
    Большое сравнение кодеков по разным параметрам и на разных файлах.
    Предназначено для тех, кто занимается использованием кодеков профессионально и полупрофессионально.

  • Сравнение видеокодеков без потерь (октябрь 2004)
    Самое большое сравнение кодеков без потерь - 15 кодеков в 3 цветовых пространствах.
    Указаны кодеки, применение которых приводит к потерям в "беcпотерьных" режимах.
    Указана суммарная степень сжатия.

  • Сравнение видеокодеков стандарта MPEG-4 SP/ASP (март 2005)
    Сравниваются видеокодеки стандарта MPEG-4 SP/ASP.
    Рассмотрены самые новые версии MPEG-4 кодеков, которые можно использовать
    для записи домашнего видео обычными пользователями.
    Оценивается прогресс в развитии кодека DivX.

  • Сравнение кодеков изображений стандарта JPEG 2000 (сентябрь 2005)
    Сравниваются кодеки изображений стандарта JPEG 2000 и кодек стандарта JPEG.
    Демонстрируется преимущество нового стандарта, можно увидеть, как отличаются его разные реализации.

  • Первое ежегодное сравнение MPEG-4 AVC/H.264 видеокодеков (январь 2005)
    Кодеки 6 компаний сравниваются между собой и с DivX.
    Tри кодека предоставлены специально для этого тестирования производителями.
    Предназначено для профессинальных пользователей и разработчиков кодеков.
    • FAQ первого сравнения видеокодеков стандарта MPEG-4 AVC/H.264
      Часто задаваемые вопросы по первому сравнению видеокодеков стандарта MPEG-4 AVC/H.264.
    • Избранные отзывы к первому сравнению видеокодеков стандарта MPEG-4 AVC/H.264
      Некоторые из приходящих к нам отзывов на первое сравнение видеокодеков стандарта MPEG-4 AVC/H.264.

  • Второе ежегодное сравнение видеокодеков стандарта MPEG-4 AVC/H.264 (декабрь 2005)
    Второе ежегодное сравнение H.264 кодеков. Сравниваются 8 кодеков.
    Шесть кодеков предоставлены специально для этого тестирования производителями.
    Предназначено для профессинальных пользователей и разработчиков кодеков.
    • FAQ второго сравнения видеокодеков стандарта MPEG-4 AVC/H.264
      Часто задаваемые вопросы по второму сравнению видеокодеков стандарта MPEG-4 AVC/H.264.

  • Субъективное сравнение современных видеокодеков (февраль 2006)
    Четыре популярных кодека сравниваются при помощи метода SAMVIQ (человек ставит оценки последовательностям, не зная, какие кодеки были использованы для сжатия).

  • Сравнение декодеров стандарта MPEG-2 (май 2006)
    Проводится сравнительная оценка качества работы 8 различных декодеров стандарта MPEG-2 при декодировании потоков с ошибками. Потоки с ошибками встречаются в спутниковом вещании и, в меньшей степени, при воспроизведении видео с DVD.

  • Сравнение WMP и JPEG 2000 (октябрь 2006)
    Ранее протестированные кодеки изображений стандарта JPEG 2000 (смотрите Сравнение кодеков изображений стандарта JPEG 2000) сравниваются с новым стандартом WMP от Microsoft.

  • Третье ежегодное сравнение видеокодеков стандарта MPEG-4 AVC/H.264 (декабрь 2006)
    Третье ежегодное сравнение кодеков H.264 стандарта. Помимо традиционного сравнения кодеков этого года, добавлено сравнение всех протестированных кодеков за последние 3 года.

  • Сравнение кодеков без потерь 2007 (март 2007)
    Тестирование 16 современных видео кодеков без потерь, в котором оцениваются степень сжатия, скорость работы и возможности распараллеливания кодеков.

  • Четвертое ежегодное сравнение видеокодеков стандарта MPEG-4 AVC/H.264 (декабрь 2007)
    Четвертое ежегодное сравнение кодеков H.264 стандарта. Помимо традиционного сравнения кодеков добавлен новый тип анализа с использованием синтетических последовательностей, также добавлены новые последовательности, новые кодеки, новые пресеты.

  • Анализ опций видеокодека x264 стандарта MPEG-4 AVC/H.264 (декабрь 2008)
    Проанализированы опции одного из лучших кодеков x264 на предмет поиска как оптимальных значений отдельных опций, так и лучших пресетов.

  • Анализ видеокодеков для компаний

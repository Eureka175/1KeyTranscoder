503 Service Unavailable

The requested website is temporarily not available due to a resource limitation. For a web site to scale, requests must complete at the same rate as they arrive. If they do not, this page is the result. This typically means that the site is experiencing a surge of traffic that it is not designed to handle. The most common reasons for this are:

  • The scripts or programs running on the site are taking too long or are nonresponsive.
  • An external resource the site needs, like a web service or database, is slow or nonresponsive.
  • A programmatic error on the site is preventing locked resources from being released.
  • A botnet or scrapers may be overloading the site.

These sorts of problems tend to go away as soon as the underlying problem is corrected, which sometimes happens automatically, so please try your request again in a few minutes. If the problem persists, please contact the site administrator for assistance.

If you are the site administrator:

  • Do not assume the problem is a lack of system resources. Our network is very scalable and can make large amounts of CPU and RAM available to busy sites on short notice. Thus, although it is tempting to automatically assume this is the problem, it is rarely the case.
  • Make sure your site's error log is enabled, and check it for more information.
  • Make sure any external dependencies are up and running and responding in a reasonable time.
  • If your site uses a database, check for slow queries or locking issues.
  • Check if temporary files, cache files, or session files are building up somewhere like your /tmp directory.
  • Make sure you do not have rewrite logs enabled.
  • See this entry in our FAQ for more general information about this error.
  • Review our FAQ entry on site scalability. Although most of the advice there is targeted toward the design phase, it may still help to identify the source of scalability issues causing this type of error.

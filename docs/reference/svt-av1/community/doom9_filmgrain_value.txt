===== POST 2 =====
IIRC, the intensity of the synthesized grain is dynamic and is based on the source characteristics. When I've tested the internal synthesis, I've used quite high values like 20 for standard non-full CGI sources and it looks quite good.

The psy branch of SVT-AV1 (https://github.com/gianni-rosato/svt-av1-psy) contains a smart, simple modification what comes to film grain synthesis - it uses a resolution dependent block for the analysis and reduces the probability of noticable grain patterns by a large amount.

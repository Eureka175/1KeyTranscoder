When open-gop is used, --gop-len sets frames between I frames and not IDR frames.

IDR frames is limited when open-gop is used, therefore seeking should be limited.

**-c hevc --gop-len 150 --open-gop**
IDR frames is 5.
```
encoded 3501 frames
frame type IDR    5 
frame type I     24,  total size  0.94 MB
frame type P    868,  total size  9.22 MB
frame type B   2609,  total size  5.49 MB
```

**-c hevc --gop-len 150**
IDR frames is 24.
```
encoded 3501 frames
frame type IDR   24
frame type I     24,  total size  0.94 MB
frame type P    887,  total size  9.33 MB
```

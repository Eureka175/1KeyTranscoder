## 6. 用例

### P1 冒烟

- C0264：NVENC / QSV / x265 / SVT-AV1，HQ，不缩放。

### P2 后端短矩阵

- NVENC：C0264、C0066
- QSV：C0264、C0066
- x265：C0066
- SVT-AV1：C0066

### P3 缩放短矩阵

- NVENC + C0264：
  - `--scale 0.5` → 1920×1080
  - `--scale 0.25` → 960×540
  - `--resize 1600x900`
  - `bilinear` / `bicubic` / `lanczos`
- QSV + C0264：`--scale 0.5`、`--resize 1600x900`
- x265 + C0264：`--scale 0.5`、`--resize 1600x900`
- SVT-AV1 + C0264：`--scale 0.5`
- 合成夹具：
  - 1080p 8-bit：NVENC `--scale 2` → 3840×2160
  - 1080p 10-bit：NVENC `--scale 0.5` → 1920×1080
  - 竖屏 1080×1920：`--scale 0.5` → 540×960
  - 4:3 3840×2880：`--scale 0.5` → 1920×1440
- 所有缩放用例默认算法必须为 **lanczos**。

### P4 保留管线

短用例：

- C0155：NVENC advanced、QSV advanced
- C0155：x265 full、SVT-AV1 full
- FX30：QSV advanced
- DJI Pocket3 33 s：NVENC advanced、QSV advanced，均加 `--preserve-metadata`

长用例（按优先级）：

1. C1305 完整：NVENC HQ，advanced
2. C1305 完整：QSV HQ，advanced
3. C1305 完整：NVENC UHQ，`--scale 0.5`，advanced
4. C1305 完整：QSV UHQ，`--scale 0.5`，advanced

### P5 音频

- C1305 完整：NVENC HQ，`--scale 0.5`，`--channel-sync`。
- `synth_4ch_pcm24_delayed`：NVENC HQ，`--channel-sync`，校验 4 路 mono PCM。
- `synth_8ch_pcm24_delayed`：NVENC HQ，`--channel-sync`，校验 8 路 mono PCM 上限。

### P6 落盘

- 成功用例：`out\.1ktwork\` 仅保留 `caps\`；
- `--keep-work`：job 目录保留；
- 失败/中断：job 目录保留；

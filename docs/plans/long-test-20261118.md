## 4. 指标与判定

1. **画质**：VMAF/PSNR/SSIM（全片段、1280 宽等比缩放、硬件解码）；
2. **码控**：视频码率、1 s/3 s 窗口 mean/p95/max vs cap、mean/cap、撞墙片段；
3. **速度**：encoder fps / pipeline fps（分硬解/软解路径）；
4. **格式对齐**：codec / pix_fmt / profile / color tags / 流清单；
5. **元数据**：Sony `rtmd/nrtm/uuid`、DJI `djmd/dbgi/tmcd`、Gyroflow 消费端；
6. **通过标准**：
   - 所有计划内 cell `rc=0` 且输出可解码；
   - 格式/流清单符合共享策略；
   - QSV 新 ICQ 的码率相对旧配置上升，且未出现不可解释的画质下降；
   - 报告与归档 SHA256 校验通过。

## 5. 失败处理与安全

- 每 cell 失败：记录 `failed_files.json`，继续下一 cell；当日结束前统一重试一次；
- 机器睡眠：保持 `powercfg` 不休眠 + keep-awake；崩溃/重启后用 `state.jsonl` 续跑；
- 磁盘：开跑前确认 ≥80 GB 空闲；每 2 h 检查输出体积与剩余空间；
- 温度/功耗：GPU 连续重载时监控温度/功耗，异常则暂停 10 min 再继续；
- 截止：**20:00 强制停止新任务**，只做汇总与报告；不允许为了“跑完”拖到夜间。
